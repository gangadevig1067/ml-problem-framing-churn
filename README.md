# ML Problem Framing & Responsible Data Card: Customer Churn

A focused one-day responsible machine learning planning, baseline evaluation, and risk documentation project using a 12-record customer churn dataset.

## Deliverables
1. **[ML Problem-Framing Memo](./problem_framing_memo.md)** – Business decision, action window, asymmetric error costs, and justification against premature ML modeling.
2. **[Responsible Data Card](./responsible_data_card.md)** – Dataset provenance, consent considerations, socioeconomic proxy skew, missingness audit, and target leakage risks.
3. **[Baseline Notebook](./baseline_notebook.ipynb)** – Exploratory data analysis and non-ML baseline rule (`last_login_days > 10`) implemented in Python.
4. **[Risk Register](./risk_register.md)** – Failure modes, fairness/gaming mitigations, and operational fallback plans.
